## What "license free" means in this project

This project was specified as "license free". That phrase is interpreted here in the
only way that is technically accurate:

> **No paid, proprietary, or commercially licensed software, API, or dataset is
> required to build, run, or demonstrate this project.**

It does **not** mean the dependencies have no licenses. Every open-source package has
a license. The commitment made here is narrower and verifiable: every dependency used
is under a **permissive** licence (MIT, ISC, Apache-2.0 or BSD-2-Clause) that allows
free use, modification, and redistribution, including for academic and commercial work.

## What this project does NOT require

| Category | Requirement |
|---|---|
| AI APIs (OpenAI, Anthropic, Gemini) | ❌ Not used. The Mini Analyst is a deterministic rule engine. |
| Paid databases (Postgres cloud, Firebase, Supabase) | ❌ Not used. SQLite, local file. |
| Cloud platforms (AWS, Azure, GCP) | ❌ Not used. Runs on localhost. |
| Payment gateways (Stripe, Razorpay) | ❌ Not used. Payment method is recorded, not processed. |
| Commercial pharma / prescription datasets | ❌ Not used. All demo data is synthetic and generated by `npm run seed` and `npm run sample:data`. |
| Excel / Office licence | ❌ Not required. Workbooks are read and written by `exceljs` (MIT); Microsoft Excel is never invoked. |
| Docker, WSL, Kubernetes | ❌ Not required. Plain Node.js on Windows PowerShell. |
| Internet connection (after `npm install`) | ❌ Not required. The application is offline-first. |

## Verifying this yourself

To re-check the full dependency tree, including transitive packages, run in PowerShell:

```powershell
npx license-checker --summary
```

(That command downloads a tool temporarily; it is not a project dependency.)

## Data sources

**No third-party data is bundled or downloaded.** All product names, suppliers,
customers, batches, and transactions in the demo database are **synthetic**, generated
programmatically by `seed/generate.ts`. Generic drug names such as "Paracetamol" are
non-proprietary International Nonproprietary Names (INN) and are not licensed content.
Brand names used in the seed are invented for demonstration and are not intended to
refer to any real commercial product.

No patient data, prescription records, medical histories, diagnoses, or insurance
claims are stored, processed, or generated by this application. See the disclaimer in
[README.md](./README.md).
